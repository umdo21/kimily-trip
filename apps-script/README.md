# Kimily Trip 백엔드 (Google Apps Script) 설정 가이드 ✈️

본 가이드는 **Kimily Trip**의 모든 데이터(여행 일정, 항공편, 호텔, 사진, 실제 지출 등)를 구글 스프레드시트와 실시간으로 동기화하는 백엔드 설정 안내서입니다.

`Setup.gs`의 **1초 자동 초기화 기능**을 이용하면 수십 개의 컬럼을 직접 타이핑할 필요 없이 클릭 한 번으로 모든 시트와 샘플 데이터가 완성됩니다!

---

## 🚀 초간단 5단계 연동 가이드

### 1단계: 구글 스프레드시트 생성
1. [Google Sheets (스프레드시트)](https://sheets.google.com)에 접속하여 **새 스프레드시트(+)**를 만듭니다.
2. 좌측 상단의 제목을 `Kimily Trip Data`로 변경합니다. (빈 시트 그대로 두시면 됩니다!)

---

### 2단계: Apps Script 편집기 열기
1. 스프레드시트 상단 메뉴에서 **확장 프로그램 > Apps Script**를 클릭합니다.
2. 새 탭에서 편집기가 열리면 좌측 상단 프로젝트 이름을 `Kimily Trip Backend`로 변경합니다.

---

### 3단계: 스크립트 코드 붙여넣기 (총 4개 파일)
편집기 왼쪽의 **파일(+)** 버튼을 눌러 스크립트를 추가하고, 본 프로젝트의 `apps-script/` 폴더 내 4개 파일 내용을 복사해 붙여넣습니다:

1. **`Code.gs`** (기본 생성된 Code.gs 내용 전체를 지우고 `apps-script/Code.gs` 내용 복사)
2. **`Writer.gs`** (`+` > 스크립트 > 파일명 `Writer` 입력 후 `apps-script/Writer.gs` 내용 복사)
3. **`PhotoUploader.gs`** (`+` > 스크립트 > 파일명 `PhotoUploader` 입력 후 `apps-script/PhotoUploader.gs` 내용 복사)
4. **`Setup.gs`** (`+` > 스크립트 > 파일명 `Setup` 입력 후 `apps-script/Setup.gs` 내용 복사)

> 💡 파일 붙여넣기 후 상단의 **디스크 아이콘(Ctrl+S / Cmd+S)**을 눌러 저장합니다.

---

### 4단계: 1초 만에 시트 자동 생성 및 샘플 데이터 채우기 🚀
1. Apps Script 편집기 상단 툴바에서 실행할 함수 드롭다운을 확인합니다.
2. 드롭다운에서 **`setupKimilyTripSpreadsheet`**를 선택하고 옆의 **실행(Run)** 버튼을 클릭합니다.
3. 처음 실행 시 **"권한 검토(Review permissions)"** 팝업이 뜹니다:
   - 본인 구글 계정 선택
   - 경고 화면에서 **`고급(Advanced)`** 클릭
   - 하단의 **`Kimily Trip Backend(으)로 이동 (안전하지 않음)`** 클릭
   - **`허용(Allow)`** 클릭
4. 실행이 완료되면 구글 스프레드시트로 돌아가 보세요!
   - `trip_info`, `flights`, `accommodations`, `itinerary`, `photos` 5개 탭이 예쁜 파란색 헤더와 함께 자동 생성되고,
   - 가족 4인(**아빠, 엄마, 하온, 하겸**)의 오사카 및 제주도 샘플 데이터가 꽉 채워져 있습니다!

---

### 5단계: 웹 앱으로 배포하고 Kimily Trip에 연결하기
1. Apps Script 편집기 우측 상단의 파란색 **배포(Deploy) > 새 배포(New deployment)**를 클릭합니다.
2. 좌측 톱니바퀴 아이콘을 눌러 **웹 앱(Web app)**을 선택합니다.
3. 아래 3가지 항목을 확인합니다:
   - **설명**: `v1.0`
   - **다음 사용자로서 실행**: **나 (본인 이메일 계정)**
   - **액세스 권한이 있는 사용자**: **모든 사용자 (Anyone)** ⭐️ (필수! 누구나 접근 가능해야 가족 디바이스에서 동작합니다)
4. 하단의 **배포(Deploy)** 버튼을 누릅니다.
5. 배포 완료 창에 나타나는 **웹 앱 URL(Web app URL)**을 복사합니다.  
   *(형태: `https://script.google.com/macros/s/AKfycb.../exec`)*
6. 브라우저에서 실행 중인 **Kimily Trip ([index.html](file:///Users/kim/trip/index.html))** 화면으로 이동합니다:
   - 우측 상단 `⚙️` (설정) 아이콘 클릭
   - **Google Apps Script 웹 앱 URL** 입력칸에 복사한 주소 붙여넣기
   - **"저장 후 연동하기"** 버튼 클릭!

---

## 🌟 (선택) 구글 지도 링크 자동 좌표 추출 트리거 설정
스프레드시트의 `itinerary` 시트에 구글 맵 공유 링크(예: `https://maps.app.goo.gl/...`)를 붙여넣었을 때 위도(`lat`)와 경도(`lng`)를 자동으로 계산해주는 기능입니다:

1. Apps Script 편집기 왼쪽 메뉴에서 **시계 아이콘 (트리거, Triggers)**을 클릭합니다.
2. 우측 하단의 **트리거 추가 (Add Trigger)** 버튼을 클릭합니다.
3. 다음과 같이 설정 후 저장합니다:
   - 실행할 함수: **`onEdit`**
   - 이벤트 소스: **스프레드시트에서 (From spreadsheet)**
   - 이벤트 유형: **수정 시 (On edit)**
4. 저장 시 권한을 한 번 더 승인해주시면 완료됩니다!

## 🛠️ 자주 묻는 질문 & 문제 해결

- **Q. 시트 데이터를 수정했는데 웹에 바로 반영이 안 돼요.**  
  - 브라우저를 새로고침(`Cmd+R` 또는 `F5`)하거나 상단 여행 드롭다운을 다시 선택하면 최신 구글 시트 데이터가 즉시 갱신됩니다.
- **Q. 웹 앱 코드를 수정한 후에는 어떻게 해야 하나요?**  
  - 코드를 수정한 후에는 반드시 Apps Script 상단 **배포 > 배포 관리 > 편집(연필 아이콘) > 버전: 새 버전(New version)**으로 변경하고 다시 **배포**를 눌러주셔야 반영됩니다.
- **Q. 사진 업로드는 어디에 저장되나요?**  
  - 본인 구글 드라이브의 `KimilyTrip/{trip_id}/photos/` 폴더에 자동 분류되어 영구 보관되며, 시트의 `photos` 탭에 링크가 자동 등록됩니다.
