# Kimily Trip - 우리 가족 여행 플래너 ✈️

Kimily Trip은 가족(부부 및 자녀)과 지인들이 함께 사용하는 **스마트 여행 일정 관리 및 추억 기록 웹앱**입니다.  
**트리플(Triple)** 앱의 직관적인 UX와 **Apple HIG** 감성을 담아 개발되었으며, **Google Sheets**를 백오피스로 사용하여 별도 서버 비용 없이 평생 무료로 운영할 수 있습니다.

---

## 🌟 주요 기능 (Key Features)

1. **단일 URL & 여행 셀렉터 (SPA)**
   - 페이지 새로고침 없이 상단 드롭다운으로 과거/현재/미래 여행을 자유롭게 전환
   - 미래 여행은 **'계획 모드'**, 지난 여행은 **'추억 모드(사진 중심)'**로 자동 전환

2. **트리플(Triple) 스타일 시간별 타임라인 & 동선 지도**
   - 카테고리별 컬러 코드(식사, 카페, 관광, 쇼핑, 이동, 숙소, 항공)
   - 순서대로 마커와 경로선(Polyline)이 연결되는 인터랙티브 지도
   - 일정 카드를 누르면 지도 마커가 포커스되고, 길찾기/지도앱 열기 지원

3. **인라인 일정 수정 & 계획 vs 실제 이중 트래킹 (여행 중 실시간 반영)**
   - **✅ 방문 완료**: 실제 시작/종료 시간 및 실제 지출 금액 기록
   - **⏭️ 스킵**: 사유(비가 옴, 대기 시간 등) 입력 및 취소선 표시
   - **🔄 일정 변경**: 대체 장소 및 실제 방문 정보 즉시 수정
   - **≡ 순서 변경**: 드래그 앤 드롭으로 일정 순서 실시간 재배치

4. **가족 사진 1인 1장 업로드 & 추억 갤러리 (여행 후 추억)**
   - 일정 장소별로 가족 구성원(아빠, 엄마, 첫째, 둘째)이 각자 디바이스에서 촬영한 사진 업로드
   - 스마트폰에서 업로드 시 브라우저 Canvas에서 1200px 자동 리사이즈 및 압축 후 저장
   - 전체 사진 모아보기 및 풀스크린 라이트박스 뷰어 제공

5. **🖨️ 여행 기록지 인쇄 & PDF 출력**
   - 상단 `🖨️ 인쇄` 버튼 하나로 A4 맞춤 여행 기록지 인쇄 또는 PDF 저장
   - 불필요한 UI(버튼, 지도 컨트롤)는 숨기고, 일정 + 사진 + 예산 대비 실제 지출 요약표 출력

6. **🍎 iOS 연동 (.ics 캘린더 & 지도앱)**
   - `📅` 버튼 탭 한 번으로 iOS 캘린더에 일정 및 알림(기본 30분 전) 자동 등록
   - `📍` 장소 탭 시 아이폰에서는 Apple Maps, 그 외 기기에서는 Google Maps 자동 실행

7. **📱 PWA 지원**
   - Safari 브라우저에서 '홈 화면에 추가'하여 네이티브 앱처럼 전체 화면으로 구동

## 🚀 빠른 시작 (Quick Start)

### 1. 즉시 둘러보기 (데모 모드)
- 별도 설정 없이 `index.html`을 브라우저로 열면 내장된 **오사카 가족여행(계획)**과 **제주도 가족여행(완료)** 샘플 데이터를 바로 확인하고 편집/업로드/인쇄를 체험해볼 수 있습니다.

### 2. 구글 스프레드시트 연동
1. [apps-script/README.md](file:///Users/kim/trip/apps-script/README.md) 가이드를 참고하여 스프레드시트를 생성하고 Apps Script를 배포합니다.
2. 웹 화면 우측 상단의 `⚙️` (설정) 아이콘을 클릭합니다.
3. 배포된 **Apps Script URL**과 (선택) **Google Maps API Key**를 입력하고 저장합니다.

## 🌐 무료 호스팅 배포 안내

빌드 과정이 필요 없는 순수 바닐라 JS/HTML/CSS 프로젝트이므로:
- **GitHub Pages**: 레포지토리를 만들고 Push 후 Settings > Pages에서 `main` 브랜치 설정
- **Vercel**: GitHub 연동 후 클릭 한 번으로 무설정(Zero-config) 배포 가능

가족들에게 해당 URL만 공유해주시면 각자의 아이폰/아이패드에서 바로 접근할 수 있습니다.
